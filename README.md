# Grammar Trainer

Веб-тренажёр грамматики по учебникам. Упражнения из книги перенесены в браузер: поля для
ответа, проверка по ключу, история ошибок и прогресс по темам. Работу можно отправить
преподавателю — онлайн через сервер или файлом, — и получить её обратно с пометками.

Сейчас есть два учебника:

- **Azar & Hagen, Basic English Grammar 4e** — глава 1, с автопроверкой по ключу.
- **みんなの日本語 初級 I** — все 25 уроков, без автопроверки: задания уходят преподавателю.

## Стек

- **Клиент**: TypeScript, React 18, Vite. Прогресс хранится в localStorage, так что работает и без сервера.
- **Сервер**: Node 22 на `node:http` без фреймворка, PostgreSQL (`pg`), логи через pino.
- **Инфраструктура**: Docker Compose, nginx, на проде Caddy с автоматическим HTTPS. По желанию Loki + Grafana для логов и GlitchTip для ошибок.
- **Проверки**: строгий `tsc`, typescript-eslint с проверкой типов, vitest.

## Запуск

Без сервера:

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # типы + линтер + тесты
```

С сервером и базой (код ученика, отправка работ, кабинет преподавателя):

```bash
cp .env.example .env     # пароль базы и ADMIN_TOKEN
make up                  # http://localhost:8080
```

## Устройство

| Папка | Что в ней |
|---|---|
| `src/` | клиент; контент глав и уроков в `src/content/` |
| `server/` | API, отдельный npm-workspace; схема базы в `server/src/schema.sql` |
| `shared/` | типы и guard-функции, общие для клиента и сервера |
| `public/img/` | картинки к упражнениям |
| `docker/`, `compose*.yml` | образы и окружения: prod, dev, тесты, логи |
